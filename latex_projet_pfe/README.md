# Projet LaTeX - Memoire PFE

Source convertie : `C:\Users\hp\Downloads\Projet Pfe - citations toutes sources.docx`

## Compilation recommandee

```powershell
xelatex main.tex
xelatex main.tex
```

Le projet utilise XeLaTeX afin de gerer correctement les accents francais et la police Times New Roman.

## Structure

- `main.tex` : fichier principal
- `chapters/content.tex` : contenu converti depuis le DOCX
- `figures/` : images extraites du DOCX

Note : les citations auteur-annee et la bibliographie du memoire ont ete conservees dans le texte LaTeX.
